# Python Programming Interview Preparation

This repository contains Python programs, exercises, and interview questions
organized by topic.

## Topics

1. Python basics
2. Strings
3. Lists and arrays
4. Dictionaries and sets
5. Functions
6. Object-oriented programming
7. Recursion
8. Searching and sorting
9. Data structures
10. Algorithms
11. Advanced Python
12. SQL questions
13. Mock interviews

## Getting started

Make sure Python 3 is installed, then run the first program:

```bash
python 01_python_basics/01_hello_world.py
```
